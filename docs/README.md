# Showcase screenshots

Captured on macOS on 22 October 2026 from Bonxie's windowed SDL renderer at 1440 × 960 pixels.
These are application captures, including the Metal procedural backgrounds, rather than offscreen
golden tests or mockups. Native window decorations and the desktop are outside the captured renderer.

The capture used temporary copies of the existing projects and source files. Navigation, theme changes,
source pinning, canvas zooming and folder organisation used the viewer's own actions; background tasks
were processed before each capture so PDFs, EPUBs, web captures and grammar diagnostics could load.
The original project database and preferences were not edited. The codebase essay's introduction was
moved into a Draft folder in the temporary copy for its writing screenshot.

The Settings screenshot shows the selected local model. The Find Sources screenshot comes from an
actual run with that model, web search, page retrieval and relevance evaluation, using the Ada
project's Readability note. It returned three candidates; the screenshot shows the results list and
the PDF preview of “Ada’s Design Goals and Object-Oriented Programming”. No candidates were added
to the original project.

The Reword captures show a manual replacement of the opening sentence in the copied Ada essay,
first with accept/cancel controls and then with the saved alternatives available for comparison.
The original wording is retained as a version. This does not demonstrate LLM prose generation.

The transcription captures are deliberately staged, as requested for the demo. A note titled
“Transcription demo (simulated audio)” receives sample speech text through Bonxie's live-dictation
and final-transcript interfaces, with the listening state simulated. No microphone was activated and
no speech-recognition inference was performed. The completed sample remains editable text.
